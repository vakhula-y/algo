## Лабораторна робота №2 (Варіант 1 Рівень 3)
Це класична оптимізаційна задача, де вартість утримання кожного елемента динамічно зростає залежно від загальної кількості обраних об'єктів. Для ефективного вирішення (щоб вкластися в часові обмеження) застосовується метод бінарного пошуку по відповіді (кількості хом'яків). На кожному кроці бінарного пошуку використовується жадібний підхід: розраховується вартість кожного хом'яка для поточної кількості $k$, масив сортується, і перевіряється, чи не перевищує сума $k$ найдешевших елементів наявний ліміт $S$.
