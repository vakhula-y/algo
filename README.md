# Лабораторні роботи з дисципліни "Алгоритми та структури даних"
​
## Виконала:  Вахула Єлизавета Анатоліївна(ІР-13)
​
## Лабораторна робота №5 (Варіант 1 Рівень 3)
Завдання вимагає програмної реалізації алгоритму пошуку зв'язаної області у двовимірній матриці, починаючи з указаних стартових координат. Необхідно ідентифікувати всі суміжні елементи (по вертикалі та горизонталі), які відповідають початковому значенню цільової клітинки, та замінити їх на нове значення. Для забезпечення стабільної роботи на великих наборах даних застосовується алгоритм пошуку в ширину (BFS) за допомогою черги або ітеративний пошук в глибину (DFS) на базі стека, що дозволяє уникнути переповнення стека викликів.
