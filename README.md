# Лабораторні роботи з дисципліни "Алгоритми та структури даних"
​
## Виконала:  Вахула Єлизавета Анатоліївна(ІР-13)
​
## Лабораторна робота №4 (Варіант 1 Рівень 3)
Метою є реалізація структури даних "черга з пріоритетами", використовуючи алгоритмічну базу збалансованого червоно-чорного дерева. Ключовою особливістю цієї реалізації є модифікований принцип сортування: елементи з найвищим пріоритетом примусово направляються у ліву гілку дерева під час балансування. Це забезпечує стабільне знаходження пріоритетного елемента у крайньому лівому вузлі, гарантуючи його швидке вилучення з логарифмічною часовою складністю $O(\log n)$.
