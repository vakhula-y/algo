# Лабораторні роботи з дисципліни "Алгоритми та структури даних"
​
## Виконала:  Вахула Єлизавета Анатоліївна(ІР-13)
​
## Лабораторна робота №3 (Варіант 1 Рівень 3)
Метою є програмна реалізація алгоритму пошуку наступного елемента (наступника) для заданого вузла бінарного дерева під час його симетричного обходу (in-order traversal). Логіка зводиться до обробки двох структурних сценаріїв: пошуку крайнього лівого вузла у правому піддереві заданого елемента, або (якщо правого піддерева немає) алгоритмічного підйому вгору через властивість parent до першого предка, для якого поточна гілка є лівою.
