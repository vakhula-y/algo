# Лабораторні роботи з дисципліни "Алгоритми та структури даних"
​
## Виконала:  Вахула Єлизавета Анатоліївна(ІР-13)
​
## Лабораторна робота №1 (Варіант 1 Рівень 2)
Завдання полягає у моделюванні обходу двовимірної сітки за специфічним зигзагоподібним маршрутом (зліва направо, потім справа наліво на наступному рядку). Необхідно алгоритмічно зіставити початковий лінійний масив елементів із клітинками матриці $m \times n$, а потім згенерувати новий одновимірний масив, який відображатиме фактичну послідовність вибірки цих елементів згідно з траєкторією руху "робота".
